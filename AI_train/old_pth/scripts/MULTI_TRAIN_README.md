# AI训练多开加速管理器使用说明

## 概述

多开训练管理器 (`multi_train_manager.py`) 是一个专门为A100云平台设计的AI训练加速工具，通过多进程并行训练实现训练速度的显著提升，同时集成钉钉机器人通知功能，让您随时掌握训练进度。

## 主要特性

### 🚀 多开加速
- **并行训练**: 在单卡A100上同时运行多个训练进程
- **智能调度**: 自动管理进程生命周期，确保GPU资源充分利用
- **动态调整**: 根据GPU利用率自动调整并行进程数量

### 🖥️ 窗口置顶与进程可见性
- **主窗口置顶**: 监控窗口保持置顶，显示详细统计信息
- **子进程可见**: 所有训练进程窗口保持可见，便于故障排查
- **实时状态**: 显示进程PID、内存使用、运行状态等详细信息
- **操作便捷**: Ctrl+C优雅停止训练

### 📱 钉钉通知
- **进度报告**: 每10次迭代发送markdown格式进度通知
- **完成通知**: 训练完成时发送详细统计报告
- **异常告警**: 训练异常时及时通知
- **频率控制**: 遵守钉钉机器人频率限制

## 快速开始

### 1. 安装依赖

```bash
# 使用uv安装依赖（推荐）
uv sync

# 或者使用pip安装
pip install -r requirements.txt
```

### 2. 配置钉钉机器人

1. 在钉钉群中创建自定义机器人
2. 获取webhook地址
3. 修改 `multi_train_manager.py` 中的配置：

```python
dingtalk_config = DingTalkConfig(
    webhook_url="https://oapi.dingtalk.com/robot/send?access_token=YOUR_ACCESS_TOKEN",
    # secret="YOUR_SECRET",  # 如果需要加签
)
```

### 3. 运行多开管理器

```bash
# 使用uv运行
uv run python scripts/multi_train_manager.py

# 或者直接运行
python scripts/multi_train_manager.py
```

### 4. 交互式配置

程序启动后会提示输入：
- **期望迭代总数**: 输入目标训练迭代次数
- **并行进程数**: 推荐4个进程（1-8可选）
- **确认开始**: 输入 `y` 开始训练

## 配置说明

### 钉钉机器人配置
```python
class DingTalkConfig:
    webhook_url: str        # 钉钉机器人webhook地址
    secret: Optional[str]   # 加签密钥（可选）
    access_token: Optional[str]  # access_token（可选）
    rate_limit: int = 20    # 每分钟最多发送消息数
    rate_window: int = 60   # 时间窗口（秒）
```

### 训练参数配置
- **并行进程数**: 推荐4个，可根据GPU内存调整
- **迭代次数**: 根据训练需求设置
- **监控频率**: 每5秒更新状态
- **通知频率**: 每10次迭代发送进度通知

## 故障排除

### 常见问题

1. **窗口置顶失败**
   - 原因: 缺少pywin32依赖
   - 解决: `uv add pywin32` 或 `pip install pywin32`

2. **GPU监控不可用**
   - 原因: 缺少pynvml或GPU不可用
   - 解决: 安装pynvml或检查GPU驱动

3. **钉钉通知失败**
   - 原因: webhook配置错误或网络问题
   - 解决: 检查webhook地址和网络连接

4. **进程启动失败**
   - 原因: 依赖包缺失或配置错误
   - 解决: 检查依赖安装和配置文件

### 性能优化建议

1. **GPU内存优化**
   - 根据GPU内存大小调整并行进程数
   - 8GB GPU: 推荐2-3个进程
   - 16GB GPU: 推荐4个进程
   - 24GB+ GPU: 推荐6-8个进程

2. **训练参数优化**
   - 调整batch_size避免内存溢出
   - 监控GPU利用率保持在80-90%
   - 避免过多进程导致资源竞争
