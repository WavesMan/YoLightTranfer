# 数据收集接口使用说明

## 📋 概述

本项目实现了一个完整的网络数据收集接口，用于采集用户设备局域网网络参数并上载到指定API接口，为AI模型训练提供数据养料。该接口遵循数据隐私保护原则，支持设备信息脱敏和用户控制。

## 🏗️ 架构设计

### 核心组件

1. **NetworkDataCollector** - 数据收集器
   - 负责收集网络质量数据、设备信息和用户行为
   - 支持批量处理和本地缓存
   - 实现数据脱敏和隐私保护

2. **DataUploadService** - 数据上传服务
   - 提供高级上传功能（压缩、加密、断点续传）
   - 支持进度监控和失败重试
   - 实现后台上传和批量处理

3. **AINetworkQualityManager** - 集成管理器
   - 将数据收集功能集成到现有AI网络质量检测流程
   - 提供统一的配置和管理接口

### 数据模型

```dart
class NetworkDataSample {
  String sessionId;        // 会话ID
  String deviceId;         // 设备唯一标识（哈希处理）
  String appVersion;       // 应用版本
  String platform;         // 平台类型
  NetworkQuality networkQuality; // 网络质量数据
  AIRecommendation? aiDecision; // AI决策结果
  bool userAccepted;       // 用户是否接受推荐
  DateTime timestamp;      // 采集时间
  // ... 其他元信息
}
```

## 🔧 集成步骤

### 1. 初始化数据收集器

```dart
// 创建数据收集器
final dataCollector = NetworkDataCollector(
  networkAnalyzer: networkAnalyzer,
  aiAdvisor: aiAdvisor,
  lanTester: lanTester,
  configService: configService,
);

// 创建数据上传服务
final uploadService = DataUploadService(
  dataCollector: dataCollector,
  config: UploadConfig(
    enableCompression: true,
    enableEncryption: false,
    maxRetryCount: 3,
    enableBackgroundUpload: true,
  ),
);

// 集成到AI网络质量管理器
final aiManager = AINetworkQualityManager(
  networkAdvisor: aiAdvisor,
  networkAnalyzer: networkAnalyzer,
  lanTester: lanTester,
  dataCollector: dataCollector,
  uploadService: uploadService,
);
```

### 2. 配置数据收集

```dart
// 启用数据收集
aiManager.isDataCollectionEnabled = true;

// 自定义配置
final config = DataCollectionConfig(
  enabled: true,
  apiEndpoint: 'https://your-api.com/network-data',
  batchSize: 50,
  uploadInterval: Duration(minutes: 30),
  includeLocation: false,
  anonymizeData: true,
);
aiManager.updateDataCollectionConfig(config);
```

### 3. 开始数据收集会话

```dart
// 在应用启动或用户同意后开始会话
aiManager.startDataCollectionSession();

// 网络质量检测时会自动收集数据
final result = await aiManager.startDetection();

// 用户接受/拒绝推荐时也会收集数据
aiManager.acceptRecommendation(); // 用户接受
aiManager.rejectRecommendation(); // 用户拒绝
```

## ⚙️ 配置选项

### 数据收集配置 (DataCollectionConfig)

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| enabled | bool | false | 是否启用数据收集 |
| apiEndpoint | String | https://api.example.com/network-data | API端点 |
| batchSize | int | 50 | 批量上传大小 |
| uploadInterval | Duration | 30分钟 | 上传间隔 |
| includeLocation | bool | false | 是否包含地理位置 |
| anonymizeData | bool | true | 是否匿名化数据 |

### 上传配置 (UploadConfig)

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| enableCompression | bool | true | 启用数据压缩 |
| enableEncryption | bool | false | 启用数据加密 |
| maxRetryCount | int | 3 | 最大重试次数 |
| retryDelay | Duration | 5秒 | 重试延迟 |
| timeout | Duration | 30秒 | 请求超时时间 |
| maxBatchSize | int | 100 | 最大批量大小 |
| enableBackgroundUpload | bool | false | 启用后台上传 |

## 📊 监控和统计

### 获取统计信息

```dart
// 数据收集统计
final collectionStats = aiManager.getDataCollectionStats();
print('待上传样本: ${collectionStats['pending_samples']}');
print('失败样本: ${collectionStats['failed_samples']}');

// 数据上传统计
final uploadStats = aiManager.getDataUploadStats();
print('总上传次数: ${uploadStats['total_uploads']}');
print('成功上传: ${uploadStats['successful_uploads']}');
```

### 监控上传进度

```dart
// 监听上传进度
aiManager.getDataUploadProgress()?.listen((progress) {
  print('上传状态: ${progress.status}');
  print('进度: ${(progress.progress * 100).toStringAsFixed(1)}%');
  print('当前批次: ${progress.currentBatch}/${progress.totalBatches}');
});
```

## 🔒 隐私保护

### 数据脱敏

- **设备标识符**: 使用SHA256哈希处理
- **网络信息**: SSID、BSSID、IP地址进行脱敏处理
- **地理位置**: 可选收集，默认关闭

### 用户控制

- 用户可随时启用/禁用数据收集
- 提供数据清空功能
- 支持用户退出数据收集

## 🛠️ 手动操作

### 触发数据上传

```dart
// 手动触发上传
final success = await aiManager.triggerDataUpload();
if (success) {
  print('数据上传成功');
} else {
  print('数据上传失败');
}
```

### 重试失败上传

```dart
// 重试失败的上传
await aiManager.retryFailedDataUploads();
```

### 清空数据

```dart
// 清空所有收集的数据
aiManager.clearCollectedData();
```
