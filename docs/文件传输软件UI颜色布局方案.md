# 文件传输软件UI颜色布局方案

## 设计理念

基于Material You设计语言，采用现代化、简洁的界面风格，强调信息层级和操作效率。设计遵循跨平台一致性原则，同时针对不同设备类型进行优化。

## 色彩系统

### 1. 主色调方案

**动态色彩系统：**
- **主色 (Primary):** `#6750A4` (紫色调，体现科技感)
- **辅助色 (Secondary):** `#625B71` (中性灰紫)
- **强调色 (Accent):** `#7D5260` (粉紫色，用于重要操作)

**状态色彩：**
- **成功色 (Success):** `#4CAF50` (绿色，传输完成)
- **警告色 (Warning):** `#FF9800` (橙色，传输中/警告)
- **错误色 (Error):** `#F44336` (红色，传输失败/错误)
- **信息色 (Info):** `#2196F3` (蓝色，信息提示)

### 2. 表面色彩层次

**浅色主题：**
```css

**深色主题：**

/* 文字层级 */

```

### 3. 设备类型色彩标识

**设备图标色彩：**
- **Windows:** `#0078D4` (微软蓝)
- **Android:** `#3DDC84` (安卓绿)
- **HarmonyOS:** `#FF0000` (华为红)
- **Linux:** `#FCC624` (Linux黄)
- **macOS:** `#000000` (苹果黑)

## 响应式布局适配

### 1. 移动端布局 (宽度 < 600px)
- 单列布局，垂直滚动
- 底部导航栏：主页、配置、我的
- 卡片宽度：100% - 边距
- 字体大小：基础14px，标题18px

### 2. 平板端布局 (600px - 1200px)
- 双列网格布局
- 侧边导航或顶部导航
- 卡片宽度：48% - 间距
- 字体大小：基础16px，标题20px

### 3. 桌面端布局 (宽度 > 1200px)
- 多列网格布局
- 固定侧边栏导航
- 卡片宽度：32% - 间距
- 字体大小：基础16px，标题24px

## 视觉层次设计

### 1. 信息层级
- **一级信息:** 主标题、重要状态 - 粗体，大字号
- **二级信息:** 副标题、描述文字 - 常规字重，中等字号
- **三级信息:** 辅助信息、时间戳 - 细体，小字号

### 2. 视觉权重
- **高权重:** 操作按钮、重要状态 - 主色填充
- **中权重:** 卡片标题、进度条 - 表面容器色
- **低权重:** 背景、分隔线 - 表面色

### 3. 交互状态
- **默认状态:** 正常色彩和透明度
- **悬停状态:** 轻微阴影提升，色彩微调
- **激活状态:** 主色强调，可能的光晕效果
- **禁用状态:** 50%透明度，灰色调

这个颜色布局方案提供了完整的视觉设计规范，可以应用于任何前端技术栈实现，确保跨平台一致的用户体验。
